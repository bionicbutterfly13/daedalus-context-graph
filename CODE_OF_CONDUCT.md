# Code Of Conduct

Daedalus Context Graph should be a serious, useful, and respectful open-source project.

Participants are expected to:

- Be direct and constructive.
- Assume good faith while staying evidence-based.
- Keep critique focused on code, design, documentation, tests, and user impact.
- Avoid harassment, personal attacks, and discriminatory language.
- Respect privacy and do not share private data, credentials, or confidential
  user context.

Project maintainers may remove comments, issues, pull requests, or contributors
that violate these expectations.
