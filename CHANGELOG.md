# Changelog

All notable changes to Daedalus Context Graph will be recorded here.

This project uses semantic versioning after the public API stabilizes. During
pre-alpha, breaking changes may happen between `0.1.0a*` releases.

## 0.1.0a0 - 2026-05-24

- Add initial pre-alpha context graph kernel skeleton.
- Add core decision trace, entity reference, artifact reference, evidence
  standard, workflow version, and in-memory graph store models.
- Add package metadata, tests, CI, and project documentation shell.
- Reserve `daedalus-context-graph` public package and repository surfaces.
