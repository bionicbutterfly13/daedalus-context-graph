# Naming

Status: private-first naming decision.

## Product Names

- **Archimedes**: operator identity and control plane.
- **Daedalus Context Graph**: graph architect, context graph, calibration graph, and
  knowledge labyrinth layer.
- **Hermes**: host runtime/platform.
- **Neo4j**: backend graph database option.
- **neo4j_context_memory**: internal Hermes provider id for the current local
  implementation.

## Recommended Public Line

> Daedalus Context Graph is a governed context graph and calibration graph library for
> AI agents, with a Hermes adapter and Neo4j backend.

## Why Daedalus

Daedalus maps cleanly to the product role: the architect who builds and
navigates the labyrinth. In this project, the labyrinth is the organization's
context graph: decisions, policies, workflows, provenance, standards, and
precedent.

Use labyrinth language carefully. It is a strong metaphor for navigation, but
public copy should emphasize clarity, governance, and reliable navigation rather
than complexity.
